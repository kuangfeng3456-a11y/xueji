### 需要注意的两处参数不一致

1. **`rules.py` 内部并存两套掌握度模型**：`MASTERY_ALPHA = 0.3`（v1，`rules.py:11,32`）与 `bkt_update()`（v2，`MASTERY_MAX_STEP = 0.30`）。主流程走 v2，但 v1 函数仍保留。**文档 0.2 节把 v1 的 0.3 列为"待改进项"，代码却还留着**——答辩时若被翻到 `update_mastery()` 会显得升级不彻底。

2. **`forecast.py` 与 `rules.py` 是两套数学模型**：`forecast.py` 用 `GAIN_PER_TOUCH = 0.12` + 线性遗忘 `×0.995`，`rules.py` 用 `BKT_LEARN = 0.08` + 指数保持率 `0.9^(t/S)`。**A6 蒙特卡洛预测出的考试日分数，和用户真实掌握度轨迹不是同一套逻辑算的**。文档第五章把它们写在同一套体系下，实际是断裂的。这是 A 层唯一的实质缺陷。
