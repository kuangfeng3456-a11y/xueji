# mistake-diagnosis

把错题归因为「概念不清 / 方法不会 / 粗心 / 时间不够」四类，并给出对应的可执行补救任务。

## 输入

- 题目文本
- 用户答案
- 正确答案
- 关联知识点（可选）

## 输出

- 错因类别（四类枚举之一）
- 错因中文标签
- 补救建议（一句可执行动作）
- 归因引擎标记（`rule` / `llm`）

## 规则

| 条件 | 类别 | 补救策略 |
| --- | --- | --- |
| 未作答或明确表示来不及 | 时间不够 | 限时训练，先易后难，超时标记跳过 |
| 答案与正确答案相似度 ≥ 0.75 但不相等 | 粗心 | 检查单位、符号和题干关键词 |
| 题目含计算/求解/证明/步骤/公式等方法词 | 方法不会 | 看例题步骤，写方法卡片，做同类题 |
| 明确表示不会 / 蒙 / 猜，或选择题相似度低 | 概念不清 | 重读定义，画概念图，做基础题 |
| 其余 | 方法不会 | 拆解解析步骤，只练卡住的那一步 |

## 提示词模板

```
你是错题归因助手。只能把错因归为以下四类之一：
concept=概念不清，method=方法不会，careless=粗心，time=时间不够。
输出 JSON：{"category":"concept|method|careless|time","suggestion":"一句可执行的补救建议"}。
不要输出其它内容。
```

## 校验要求

- 大模型输出必须落在四类枚举内，否则回退规则引擎；
- 建议必须可执行，禁止空泛表述；
- 归因写在错题记录中，供周报统计。
