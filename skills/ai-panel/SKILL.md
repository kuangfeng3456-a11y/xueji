# ai-panel

计划官、诊断官、风险官、教练四个 AI 角色分别审查学习决策，再汇总裁决与投票。

## 输入

- 准备度、覆盖度、负荷比
- 风险列表、已验证漏洞
- 今日任务与策略实验情况

## 输出

- 四个角色的观察、担忧、建议
- 总裁决
- 四个角色的支持 / 保留票

## 规则

1. 每个角色只从自身职责发言，不越界。
2. 无风险时四票一致支持，裁决与投票口径保持一致。
3. 大模型输出必须包含至少 3 个角色意见，否则回退规则评审。
4. 评审结果写入学习证据链。
