# risk-rescue

识别备考中的五类风险，给出原因、建议动作与调整前后对比，用户确认后才修改计划。

## 输入

- 准备度、知识覆盖、负荷比
- 逾期任务、违约记录、到期复习数
- 已验证漏洞、策略实验情况

## 输出

- 风险列表：知识 / 时间 / 执行 / 记忆 / 策略
- 每条风险：等级、触发原因、建议动作、调整前后预计值
- 救援执行结果：前后准备度、今日任务数与分钟数、具体变更

## 规则

1. 知识风险：已验证漏洞或高权重薄弱点 → 生成修复任务。
2. 时间风险：负荷比 >1 → 压缩低优先级任务并重排。
3. 执行风险：逾期 ≥2 → 保留 1 个最小任务，其余顺延。
4. 记忆风险：到期复习 ≥5 → 插入 15 分钟复习任务。
5. 策略风险：无实验或收益未知 → 引导去策略实验室。
6. 所有调整先返回建议，用户确认后才执行。
