# feynman-check

把知识点讲给 AI 听，对照预置的「标准讲解要点」做覆盖判定，专抓「自以为熟但讲不全」的熟练度错觉。

## 输入

- 知识点（可选，留空则由系统挑「自测分不低但错过题」的点）
- 讲解原文（文字，或语音转写）

## 输出

- 要点覆盖率（讲到的条数 / 总条数）
- 讲到的要点、漏掉的要点（带 hint 说明）
- 疑似表述问题（仅供参考，不参与计分）
- 熟练度错觉榜：掌握分高但覆盖率低的知识点

## 规则

1. 要点清单在开讲前预置在服务端，**不下发给用户**——照着清单念不算讲解。
2. 覆盖判定只认「讲没讲到」：同义表达、符号不同写法算命中，只沾边不算。
3. 要点生成顺序：模型 → 知识图谱子节点 → 通用骨架（定义 / 前提条件 / 用法 / 易错点 / 与其他知识的联系），`engine` 如实标注。
4. 疑似表述问题单独列出，明确标注不参与计分。
5. 一次讲解只能核对一次，避免反复改到全覆盖。

## 实现位置

- 接口：`POST /api/teaching/feynman/start`、`POST /api/teaching/feynman/submit`、`GET /api/teaching/feynman/profile`
- 服务：`backend/app/services/reverse_teaching.py`
- 页面：练习与复盘 → 讲与判 → 费曼讲解
