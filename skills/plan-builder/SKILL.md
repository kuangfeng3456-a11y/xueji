# plan-builder

按倒计时、每日可用时长与知识点优先级生成周计划和每日微任务，并为每个任务生成「为什么今天安排这个」的解释。

## 输入

- 考试名称、考试日期
- 每日可用分钟
- 知识点树（父节点 + 叶子节点权重）
- 当前掌握度与下次复习日期

## 输出

- 周计划（默认 7 天，可配置 1~30 天）
- 每日 3 个微任务（学习 / 复习 / 练习 / 补救）
- 每个任务的时长、优先级、安排理由

## 规则

1. 任务只安排到叶子知识点，父节点只用于组织知识树。
2. 优先级：`weight × (1 − mastery) × urgency`，`urgency = 1 + 3 × e^(−剩余天数 / 14)`。
3. 每日任务数 3 个；复习任务优先占用约 30% 时长。
4. 每日总时长不超过用户设定的可用分钟。
5. 使用「已排次数」衰减，避免连续多天重复同一批知识点。
6. 掌握度 < 0.35 生成「学习」任务，0.35~0.7 生成「练习」，到期复习生成「复习」。

## 安排理由模板

```
掌握度偏低，先补基础概念（当前掌握度 0.32）。
优先级 2.31 = 权重 1.5 × 未掌握 0.68 × 临近系数 2.26；距考试还剩 18 天。
```

## 提示词模板（可选，仅用于润色理由）

```
你是学习计划助手。请把给定任务的规则化理由改写为一句不超过 45 字的中文说明，
必须保留掌握度、剩余天数等数字，不得改变任务安排。只输出说明文本。
```
