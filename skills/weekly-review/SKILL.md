# weekly-review

汇总一周任务、掌握度历史与错题记录，输出周报与下周重点。

## 输入

- 一周任务（日期、状态、时长）
- 掌握度历史快照
- 错题记录（类别、知识点）
- 考试剩余天数

## 输出

- 周报正文（概览 / 掌握度变化 / 错题分析 / 下周建议）
- 完成率
- 掌握度变化
- 下周重点知识点
- 可选：大模型教练点评

## 规则

1. 完成率 = 本周完成任务数 / 本周任务总数。
2. 掌握度变化 = 当前掌握度均值 − 周初（周一或之前最近一次）快照均值。
3. 下周重点取掌握度最低的知识点。
4. 错题按四类错因统计分布。
5. 大模型只允许在统计数字不变的前提下补充点评，禁止改写数字。

## 周报模板

```
【本周概览】2026-11-02 至 2026-11-08，完成 18/22 个任务，完成率 82%，累计学习 540 分钟。
【掌握度变化】平均掌握度较周初上升 0.07，当前薄弱点：听力篇章、仔细阅读。
【错题分析】本周记录 6 道错题：方法不会 3 道；概念不清 2 道；粗心 1 道。
【下周建议】下周优先补「听力篇章」，每天安排 20 分钟基础回顾 + 10 分钟同类题。
```
