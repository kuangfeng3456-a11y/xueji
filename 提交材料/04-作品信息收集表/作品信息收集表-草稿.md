## 三、作品简介（约 300 字）

学迹是一个以「学习状态数据」为核心的自适应 AI 学习教练，面向有明确考试目标的大学生（四六级、考研、计算机等级、HCIA 等）。系统用可复算的规则内核生成、执行并动态调整个人学习计划，用大模型完成语义理解与表达——「规则管事实、模型管表达」：排程、掌握度、复习间隔、考试日预测全部由程序规则产生，大模型只负责语义归因与文案表达，且每一处输出都有规则兜底。核心闭环为「生成 → 执行 → 反馈 → 重排」：落后、错题增多、临近考试时计划自动调整，并输出调整理由。产品内置学习驾驶舱、知识漏洞地图、未来模拟实验室、风险救援中心、策略实验室五项决策级创新，以及探针出题官、思维路径回放器、知识迁移压力测试、多智能体评审团等 AI 决策增强能力；每个 AI 判断保留学习证据链，可逐条追溯。

## 四、创新点

1. 考试日掌握度预测：蒙特卡洛 1000 次采样输出 P10–P90 区间，并反推达成目标所需每日时长；
2. 状态感知的疲劳干预：专注中断、离开页面、错题增长合成疲劳指数，偏高时一键降载；
3. AI 随堂测闭环：出题 → 判分 → 四类错因归因 → 错题入库 → 掌握度更新 → 计划重排一次完成；
4. 决策级五模块：驾驶舱 / 漏洞地图 / 未来模拟 / 风险救援 / 策略实验室；
5. AI 决策增强：探针出题官 / 思维路径回放 / 迁移压测 / 多智能体评审团 / 认知负荷调节 / 反脆弱挑战；
6. 学习证据链：每个 AI 判断保留数据快照、触发规则与模型来源，逐条可追溯。

## 六、技术架构摘要

- 四层架构：Vue3 SPA（35+ 页面）→ FastAPI（46 个路由模块、214 个 API 端点）→ rules.py 纯函数规则层 → MySQL/Redis/对象存储（自动降级）；
- 四智能体：Planner / Diagnoser / Coach / Reporter，共享规则内核，各带可选 LLM 增强；
- 提示词工程：19 条提示词（P00–P18）版本化注册，统一信封校验，全量调用审计；
- 工程规模（2026-11-16 实测）：后端 35,155 行 + 前端 31,468 行，54 张数据表，908 个测试函数，15 个 Skill 包。
